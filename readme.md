# COVID-19 Data Exploration & Analysis in SQL
 
# Project Overview

Analyzed COVID-19 deaths, cases, population, and vaccination data using SQL to identify trends and calculate key metrics related to infections, deaths, and vaccinations.

#  Objective

Explore COVID-19 data using SQL and analyze infection, death, and vaccination trends across countries and continents.

# Analysis Performed
Explored COVID-19 deaths and vaccination datasets.
Calculated death percentage and infection percentage.
Identified countries and continents with the highest death counts.
Analyzed global daily cases and deaths.
Joined COVID-19 deaths and vaccination datasets.
Calculated rolling vaccination counts using SQL window functions.
Calculated the percentage of population vaccinated.
Created tables and views for further visualization.
